# 4-Model Business Valuation Calculator

A simple Streamlit calculator for four common business valuation approaches:

1. Discounted Cash Flow (DCF)
2. Comparable Companies
3. Precedent Transactions
4. Asset-Based Valuation

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Then open the local URL shown by Streamlit.

## Deploy on GitHub + Streamlit Community Cloud

1. Create a new GitHub repository.
2. Upload `app.py`, `requirements.txt`, and `README.md`.
3. On Streamlit Community Cloud, choose **Deploy app**.
4. Select your GitHub repository and `app.py`.
5. Deploy.

## Important

The default numbers are illustrative TCS-style inputs from the worked example. Replace them with verified figures from the company's latest annual report/filings.

This tool is educational and does not provide investment advice.
